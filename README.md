# Resala application

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
    npx expo start
   ```
##  Time to finish the task
Considering that I had No knowledge about react native it took me around 5.5 hours to get acquainted with react native and to finish the task
